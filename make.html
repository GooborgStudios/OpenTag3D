      Warning: NFC Tools iOS App Bug
    

    

      The NFC Tools iOS app has a bug where writing a tag from an imported .json
      profile corrupts any byte value of 128 or higher, garbling your tag data.
      This happens even with profiles exported by the app itself, so it is
      something that Wakdev must fix.
    

    

      iOS Users: unfortunately, because of this bug, there is currently no way
      to read or write OpenTag3D tags on iOS, as Apple has not yet implemented
      Web NFC. You will need to use a different device or platform to write your
      tags. We are considering developing a native iOS app to support this in
      the future, but it is not currently available. Please use another device,
      such as a Flipper Zero or
      Android device, in the meantime.
    

    

      Android Users: while the bug is not present on the Android version of the
      app, we recommend using Web NFC to read and write your
      tags.
